## 1 核心定义

1. **信卡 = 贴满标签的目标**（目标是骨，标签是衣，骨肉一体）；
2. **标签 = 最小记忆单元**（比卡还小）——需要被信卡规则验证的东西，**验的是标签不是卡**；
3. **置信度 = 目标的属性标签**（也是标签，不是独立账）——落位在每条标签的 `验证.置信度`；
4. **记忆 = 写卡，认知 = 读卡**（读写信卡即全部认知记忆的存取面）；
5. **一卡一事**：目标单体 + 单标签值长上限（结构兜底；语义层拆卡留人工/蒸馏段，不吹机械判全）。

## 2 schema v1.0.0（信卡 = 目标 + 标签集）

### 2.1 三层结构

```
信卡 = 目标 + 标签集
目标 = {kind, name, scope}                 ← "谁"
标签 = {
  维度: 属性|置信度|来源|凭证|时间,
  key, 值,
  验证: {凭证锚, 来源档, 过规则, 置信度, 证据数, 反例数, 强制重写},
  时间: {created_at, last_evidence_at, half_life_days}
}
```

### 2.2 卡级字段

| 字段 | 类型 | 必填 | 谁定 | 说明 |
|---|---|---|---|---|
| `card_schema_version` | str | ✅ | 引擎 | 版本头，现行 `"1.0.0"` |
| `xinka_compat` | str | ✅ | 引擎 | 对齐档 `"0.3"`（v0.3 字段对照见 §10） |
| `card_id` | str | — | **引擎** | 幂等键，按 目标(kind\|name) 派生 `xc-<hash12>`；草稿自带即 R09 拒（防身份劫持） |
| `card_type` | enum | ✅ | 作者 | 对象卡\|对己卡组\|课卡\|刀谱卡\|基础卡\|坑账卡（六卡类，见 §3） |
| `目标.kind` | enum | ✅ | 作者 | 实体\|对象\|任务\|概念\|我 |
| `目标.name` | str | ✅ | 作者 | "谁"，非空 |
| `目标.scope` | str | ✅ | 作者 | 一句话界定适用域 |
| `标签集` | list | ✅ | 作者 | ≥1 条标签（最小记忆单元） |
| `账` | obj | — | **引擎** | revision / content_hash / created_at / updated_at / usage_count / last_usage / tier——引擎账，草稿私填即 R09 |

### 2.3 标签级字段（验的是标签）

| 字段 | 类型 | 必填 | 谁定 | 说明 |
|---|---|---|---|---|
| `tag_id` | str | — | **引擎** | `t1..tn`，草稿私填即 R09 |
| `维度` | enum | ✅ | 作者 | 属性\|置信度\|来源\|凭证\|时间 |
| `key` | str | ✅ | 作者 | 标签名，非空 |
| `值` | str | ✅ | 作者 | 非空、≤400 字符（超长即拆，一卡一事） |
| `验证.凭证锚` | str | ✅ | 作者 | 只存指针不存原文（语法见 §5） |
| `验证.来源档` | enum | ✅ | 作者 | 亲验\|转述\|待验（来源三档，见 §5） |
| `验证.过规则` | bool | — | **引擎** | 入卡必为 true，草稿私填即 R09 |
| `验证.置信度` | float | — | **引擎** | 0–1，初值按来源档（0.8/0.55/0.3，见 §5） |
| `验证.证据数/反例数/强制重写` | int/int/bool | — | **引擎** | 代谢账（见 §7） |
| `时间.created_at` | iso | — | **引擎（机钟）** | 机械注入，禁手编 |
| `时间.last_evidence_at` | iso | — | **引擎（机钟）** | 半衰期起算点 |
| `时间.half_life_days` | int | — | **引擎** | 90/180/365（按维度，见 §7） |

### 2.4 机管字段（时间红线：草稿私填即 R09 拒）

卡级 `账`、`card_id`；标签级 `tag_id`、`时间`；验证块 `过规则`、`置信度`、`证据数`、`反例数`、`强制重写`；目标块机管字段（时间/账/tier/usage 等走私进目标同拒）。时间戳一律机钟机械注入——手编时间戳/手编置信度/手编过规则进不了卡。

## 3 卡类（六类 + 对己卡组九类含星）

### 3.1 六卡类

| 卡类 | 贴什么 | 备注 |
|---|---|---|
| 对象卡 | 世界（人/事/物的印象） | 对人对事对物的印象都在卡上 |
| 对己卡组 | 自我（九类，见 §3.2） | 自我面 |
| 课卡 | 教材（一课一卡：知识点/难度/前置/练习/考核） | 学习系统 |
| 刀谱卡 | 技能（用法/时机/角度） | 怎么用、什么时机、什么角度 |
| 基础卡 | 系统自述（记录卡库怎么运行） | 白箱 |
| 坑账卡 | 反例（什么活/踩什么坑/怎么爬出） | 复盘粮食 |

### 3.2 对己卡组九类（含星卡）

| 卡 | 目标.name | 贴什么 |
|---|---|---|
| 做事风格卡 | 我·做事风格 | 我怎么干活 |
| 说话风格卡 | 我·说话风格 | 我怎么说话 |
| 自我介绍卡 | 我·自我介绍 | 我是谁 |
| 北极星卡（星卡） | 我·北极星 | 人生追求（方向与动力）——自卡，不外挂 |
| 常识卡 | 我·常识 | 世界认知（九级：幼儿→博士→社会→企业） |
| 做事底线卡 | 我·做事底线 | 红线 |
| 做人底线卡 | 我·做人底线 | 三观 |
| 能力卡 | 我·能力 | 我会什么 |
| 关系卡 | 我·关系 | 我是谁的谁 |

- 卡身份口径〔暂钉〕：card_id 仍按 目标(kind|name) 引擎派生；九类以 `目标.name="我·<类别>"` 区分，类别同时落普通标签 `对己类别`（作者标签，非机管字段）。
- **同 schema 零特权**：对己卡与对象卡同 schema、同闸门（R01–R09）、同代谢、同幂等、同墓碑——没有任何旁路。

## 4 入卡验证四门与验证码表

四门（入卡必过，验证不过写口物理拒绝——不是提醒是拒绝）：

| 门 | 查什么 |
|---|---|
| 真伪 | 结构（六卡类/维度 enum/目标名非空/值非空≤400）；file: 锚存在性真查 |
| 来源三档 | 来源档合法；卡上须有来源维度标签；来源标签与逐标签档交叉校验（见 §5） |
| 凭证锚 | 在场→指针语法→存在性（限锚基内）→守密（锚塞原文即拒） |
| 合规 | 密钥/私钥/银行卡/身份证类敏感件入卡即拒（启发式：关键词+形制指纹，宁严勿漏） |

### 验证码表（精确码；负例判据=拦因集合==期望集合，多码乱飞即不过）

| 码 | 拦什么 | 要点 |
|---|---|---|
| R01 | 结构不合 | 卡类/维度非法、key/值空、值超 400、标签集缺失 |
| R02 | 目标缺名/越类 | 目标块缺失、kind 越枚举、name/scope 空 |
| R03 | 来源档非法/来源自相矛盾 | 档不在三档；来源标签值≠自身档（自证矛盾）或值强度>最弱标签档（超售高报）——低报不拦 |
| R04 | 来源标签缺失 | 卡上无来源维度标签 |
| R05 | 凭证锚缺失/不合指针语法 | 不在指针语法白名单内即拒 |
| R06 | 锚不存在或越出锚基 | file: 真查存在性；`../` 穿越/绝对路径/符号链接逃逸解析后越出锚基即拒 |
| R07 | 守密（锚塞原文） | 锚位置塞原文不塞指针——守密红线 |
| R08 | 合规（密钥/敏感数据） | 关键词式（中英，分隔符/空白两式）+ 裸密钥形制指纹（sk-/ghp_/github_pat_/AKIA/AIza/xox/JWT/私钥块/长数字号段） |
| R09 | 机管字段私填 | 手编时间戳/置信度/过规则；草稿自带 card_id/tag_id；目标块走私机管字段 |
| ZOMBIE | 尸变拒复活 | 撞卡级墓碑或含亡标签（见 §7 防尸变） |

未达如实（照登）：R08 为启发式——误伤面（关键词+含数字短语、中文散文值、16–19 位长数字、银行卡/身份证形制撞号段）会拦；残漏面（无符号短值、未收录形制、语义改写混写、表外新词）会漏。语义层"一卡多事"只做结构兜底；`url:`/`doc:`/`session:` 锚只验形不验存在。

## 5 来源三档与凭证锚

### 5.1 来源三档

| 档 | 含义 | 初置信度〔暂定〕 |
|---|---|---|
| 亲验 | 自己亲历/亲测 | 0.8 |
| 转述 | 转述他人（可回溯） | 0.55 |
| 待验 | 未经核验 | 0.3 |

- 交叉校验：来源标签值必须与自身 `验证.来源档` 一致（自证一致）；来源标签值强度不得大于卡上最弱标签档（禁超售高报）。**低报不拦**（不吹不谎）。
- 反直觉/高价值结论标待验起步，凭证据升级（升档走代谢，§7）。

### 5.2 凭证锚指针语法（只存指针不存原文）

```
file:<相对库根路径>[#L行号]     ← 本地件指针，存在性真查，限锚定库内
                                  （../穿越/绝对路径/符号链接逃逸解析后越出锚基即 R06）
url:https?://...                ← 网页指针，离线只验形（存在性未验）
doc:<文档号>                    ← 文档号指针（只验形）
session:<会话id>@<ISO时刻>      ← 会话锚（只验形）
```

白名单语法之外的内容一概视为原文，拒收（R07）——脱敏与守密落在结构上，不是口号。

## 6 归一化（含零宽剥离，全库同口径）

- **全文位剥除零宽/不可见字符**（零宽空格/软连字符/词连接符/方向控制/变异选择符/BOM/蒙文元音分隔等）后再判：纯零宽串=空串（零宽空值全堵）；零宽拆词（如 pass+零宽+word）剥除后照样命中——不绕扫描。
- **三面同口径**：空值判（key/值/name/scope）、合规扫描面（R08）、锚判别（norm_anchor：剥首尾空白/零宽，落盘存归一化指针）全部走同一归一函数；判据面一处归一、全库（含账本行过滤、提取面、桥面）同口径跟齐。
- **判定面归一，不改写直写落盘的原文**（锚落盘亦存归一化指针）；值长上限按原串计长（偏严不偏松）。
- 实测：零宽拆词 12 变体 12/12 全拦、零宽空值 6 变体 6/6 全拦、变异测试 10 组 10/10 拆即红/还原即绿（§12）。

## 7 置信代谢与幂等、防尸变

### 7.1 置信度代谢（涨慢跌狠 + 半衰期 + 三档沉底）

| 件 | 规则 | 状态 |
|---|---|---|
| 涨慢跌狠 | 证据+1 → +0.05；反例+1 → −0.25 | 方向定稿，步长〔暂定〕 |
| 强制重写 | 反例数≥3 置强制重写旗，不许原样赖着 | 定稿 |
| 半衰期 | 淡化后 = 置信度 × 0.5^(年龄/半衰)；到期自动淡化，不改原账 | 90/180/365 天定稿；维度映射〔暂定〕：时间90/属性180/置信度180/来源365/凭证365 |
| 三档沉底 | 活 ≥0.6 / 休眠 ≥0.3 / 归档 <0.3（按淡化后置信度均值） | 阈值〔暂定〕；只沉底不删档（归档卡仍在账可回捞） |
| 引用即投票 | cite → usage_count+1，喂回选段/删段 | 定稿 |

参数纪律：〔暂定〕项待联调实测后共契改数，禁各自擅改。

### 7.2 幂等（card_id upsert）

- `card_id` 一律引擎派生（按 目标(kind|name)，同目标=同卡）；草稿自带即 R09 拒；
- 同卡同身（卡身哈希 `h-<hash24>` 相同）→ 幂等跳过（skipped），账面不留重复修订；
- 同卡异身 → 修订号 +1，旧修订留账可回溯。

### 7.3 防尸变（删除防复活）

- 删除=墓碑（不物理删，账留可回捞）：卡级 `delete` + 亡标签 `delete_claim` 两级；
- 亡标签指纹 `ck = hash(目标名|key|值)`：被删 claim 在任何卡上禁复活；
- 撞卡级墓碑或含亡标签 → ZOMBIE 拒。语义等价改写的复活检测未做（照登）。

## 8 MCP 四口契约（壳↔信卡库）

契约单源（文档/tools 列表/机检同一源，禁两处各写）；入参出参一律纯文本 JSON；**领域拒绝=正常出参**（status=rejected + 拦因码），传输/协议错才走 JSON-RPC error；机管字段永不出现在入参。

| 口 | 入参 | 出参 | 错误口径 |
|---|---|---|---|
| `xinka_write_card` 写卡（记忆=写卡） | 卡草稿（card_type+目标+标签集） | {status: admitted\|skipped\|rejected, card_id, revision, content_hash, 拦因码[], 墓碑?} | 验证不过/尸变=rejected 正常出参；幂等同身=skipped |
| `xinka_read_card` 读卡（认知=读卡） | {card_id} | 活卡全卡（schema v1.0.0） | 无此卡 not_found；只读不回写 |
| `xinka_search` 检索 | {target, query?, top_k?, mode: 属性集\|记忆片} | 属性集/记忆片 + 对账{点查命中,扩散新增,合分入选,回写} | 空库/无命中=正常出参（对账四数如实低值） |
| `xinka_validate` 验证 | 同写卡草稿 | {ok, 拦因码[], 逐标签判词, 标签数} | 干跑不落盘，与写卡同一判据 |

检索为四段整体件：**点查 → 扩散 → 合分 → 回写**（一个目标进、一组属性出，对账四数随出参回单）。

协议口径（JSON-RPC 2.0）：未知 method → -32601；params 非对象/未知工具/工具名非法 → -32602；未预期内错 → -32603（如实报不吞）；通知（无 id）零回执；异常锚（嵌 NUL/不可解析）回干净拦因码（file:→R06，其余指针形→R05），不进 isError。

## 9 对己卡机制（自我=对己信卡组）

- **自我=对己信卡组**（九类多张卡，不是一张）；对己卡自下而上立起来——自立的卡长出来才是本相，外挂的是壳；
- **多卡并存**：场景切换=哪张卡在前面（同类别多卡按 场景标签→置信度→引用→名字 定序取前置，通用卡兜底）；
- **卡冲突=登记不自动改**：同类别同 key 不同值且场景域重叠 → 登记冲突（事件账留痕），处置四式=划场景/增厚/改/褪——自我矛盾=不同信卡说话，不是虚伪是卡多；
- **成长=卡在增、在厚、在改**：长卡四式=增（新卡立）/厚（加标签加证据）/改（改值 rev+1）/褪（亡标签/三档沉底）；
- **星卡不外挂**：北极星=九类之一（目标.name=我·北极星），方向与动力长在自卡组里；
- 防尸变、置信度、幂等对对己卡同样生效（零特权，§3.2）。

## 11 开源与边界

- **结构开源**：schema、验证码表、契约、算法框架（检索四段等）为可公开结构；
- 核心引擎（匹配与推导）为闭源件——只开结构，不带推导；
- 用户标签数据在本地（用户主权），不暗取；
- 许可以各发布仓 LICENSE 为准。

## 13 未达如实（本标准不吹的部分）

1. 语义层"一卡一事/多事拆卡"只做结构兜底（目标单体+值长上限），语义判全留人工/蒸馏段；
2. R08 合规眼为启发式（关键词+形制指纹），误漏两面照登（§4）——语义级"这是密钥"判留后；
3. `url:`/`doc:`/`session:` 锚只验形，存在性离线未验；
4. 代谢参数（涨跌步长/维度↔半衰映射/沉底阈值）为〔暂定〕值，待联调实测共契定数；
5. 对己卡「我·<类别>」命名口径〔暂钉〕；常识九级档位表只记声明不判档；
6. 语义等价改写的亡标签复活检测未做（墓碑只挡三元组精确同款）；
7. 契约机检为最小 JSON Schema 子集（type/required/enum/长度界/多余键）；流式/分页未做；网络传输面鉴权未定（本地 stdio=用户机器信任边界）；
8. v0.3 四卡类↔六卡类映射表〔未钉死〕。
