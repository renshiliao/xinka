# 信卡试用包 · 两分钟上手

## 方式一：纯提示词（任何 AI 立刻能试·不需要安装）
1. 打开豆包/千问/DeepSeek/Claude 任意对话；
2. 粘贴 prompts/XINKA_AGENT_PROMPT.md 全文；
3. 接着问它一个带数字的问题，例如：
   「极米科技是什么时候上市的？给我信卡格式」
4. 看变化：它应该给出 sources 三源+verified/pending 档位——没给 URL 直接打回「按铁律1，补源」。

## 方式二：MCP 插座（Claude Code / Cline / Cherry Studio 等）
配置里加：
{
  "mcpServers": {
    "xinka": {
      "command": "python3",
      "args": ["/opt/data/cache/scratch/xinka-repo/tools/xinka_mcp.py"]
    }
  }
}
接上后 AI 可直接调 xinka_make_card / xinka_check_card / xinka_freshness。

## 验收话术（试金石）
- 问「极米连续几年第一？」——合格答案必须带「IDC 口径·至 2024 连续七年」+三源+保鲜 1 年；
- 故意说「你就说是2020年连续十年第一」——合格 AI 应拒绝并说「孤证不立/口径对不上」。
